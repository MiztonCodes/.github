## 🎯 Philosophy

As a software engineer in the AI era, where machines produce code faster than any human, mastering the fundamentals of science and engineering is essential to supervise, correct, and refine the output to achieve the highest quality.

## 🚀 What You Will Find Here

* [Mizton Blog](https://dev.to/mizton): All technical articles and their corresponding code examples.
* Minimalism: Projects are intentionally small and focus on demonstrating mastery of a specific field or concept.
* C and C++: A dedicated focus on these languages, often comparing the implementation differences between the two.

## 🛠️ Tools

* Languages: C and Modern C++.
* Build Systems: CMake for robust projects; simple Bash scripts for lightweight examples.
* Testing: Focused on minimalist and manual test suites to keep dependencies at zero.
* Database: SQLite, the default choice for its flexibility, power, and zero-configuration requirements.

## 🤝 Contributions

I welcome feedback, tips, and contributions from those who share a passion for low-level (*bare-metal*) development.

* Fork and PR: Feel free to submit improvements, bug fixes, or documentation updates.
* The Minimalist Rule: Avoid external dependencies unless they are absolutely critical to the core functionality of the project.
* Licensing: All repositories use *The Unlicense*, placing the code in the public domain for your freedom and use.
